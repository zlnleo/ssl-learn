# Swin Transformer 最小复现学习路径

> 目标：**从论文出发，用最少的代码、最快的反馈，把 Swin 的机制逐个复现出来**。
> 每个里程碑都有**可执行的验收标准**（具体数字），过了才算懂。
> 参考代码：`paper/minimal_swin.py`（单文件总装）；深挖材料：模块 01-09（每个机制一整个文件夹）。

## 0. 复现哲学（先读这 5 条）

1. **先对表，后训练**：参数 28.3M、MACs 4.5G、shape (2,3,224,224)→(2,1000) 三个数字对不上，代码一定错——先修模型再谈训练。
2. **过拟合 1 个 batch 是标准试金石**：任何复现代码，第一步训练验收都应该是"喂 8 张图 20 步，loss 从 ln(类别数) 掉到接近 0"。能做到 = 前向/反向/优化全链路正确。
3. **机制 ≠ 配方**：81.3% 需要 EMA/RandAug/Mixup 等训练配方，但**窗口、移位、掩码、合并这 4 个机制与配方无关**——先复现机制，配方最后再说。
4. **每个机制配一个"为什么"实验**：复现代码跑通只是开始，能回答"shift 有什么用在哪儿可见"（可达 token 16→64）才算理解。
5. **一份代码，两套口径**：论文 4.5G 是 fvcore 口径（1 MAC = 1 FLOP），严格口径是 9G——复现时先确认自己用的是哪个。

## 2. 逐里程碑指南

### M0 读论文（2h）
- 读：Abstract → Figure 1 → Figure 3 → Table 1 → Table 4 → 3.1 节全文。其余实验表扫一眼即可。
- 配套：《论文讲解.md》第 4 节精读 + 第 9 节"论文没写但代码必须做对"的 8 条。
- 验收：合上论文，画出（a）4-stage 架构图；（b）移位窗口的 9 宫格示意；写出 Ω(MSA) 与 Ω(W-MSA) 公式。

### M1 窗口划分/还原（1h）
- 实现：`minimal_swin.py` 第 ① 节的 `window_partition/window_reverse`。
- 深挖：模块 02（view/permute 的 strides 本质、为什么必须 contiguous）。
- 验收：`python 02_window_partition/test_window_partition.py` 全过；构造"位置 id 张量"确认窗口编号行优先。

### M2 窗口注意力（2h）
- 实现：`minimal_swin.py` 第 ③ 节的 `WindowAttention`（此时先删掉偏置和 mask 两行）。
- 验收（对表）：
  - 公式：Ω(W-MSA) = 4hwC² + 2M²hwC；
  - 数值：hw=3136, C=96, M=7 → 145.1M MACs vs 全局 2.00G（13.8×）；
  - 代码：`01_window_attention/experiment.py` 实测耗时/显存与公式同量级。
- 深挖：模块 01 的 math.md（softmax 为什么除以 √d、多头怎么拆）。

### M3 相对位置偏置（1.5h）
- 实现：`build_relative_position_index` + 偏置表 + `attn = attn + bias` 一行。
- 验收：M=7 时索引值全部落在 [0,169)；对角线统一为位移 (0,0) 的行号；转置对称性（index[a,b] 与 index[b,a] 是相反位移）。`python 03_relative_position_bias/test_relative_position_bias.py` 全过。
- 深挖：模块 03（三种位置编码对比、为什么窗口内只需 (2M-1)² 种）。

### M4 移位窗口 + 掩码（3h，**最难，最值得花时间**）
- 实现：`SwinBlock` 里的 pad → `torch.roll(-s)` → 分窗注意力 → reverse → `torch.roll(+s)` → crop；`build_attn_mask` 九宫格。
- 验收：
  - `unroll(roll(x)) == x`（循环移位可逆）；
  - 8×8 / M=4 / s=2 的 mask：屏蔽元素共 448 个、值域只有 {0, -100}、对角线全 0（`05_attention_mask/experiment.py`）；
  - **机制实验（本路径的灵魂）**：两层注意力后每个 token 的可达集合——W-W 两层=16 个（困在本窗口），W-SW 两层=64 个（`experiments/exp2_window_vs_shifted.py --skip-train` 的 ASCII 覆盖图）。
- 深挖：模块 04（roll 的 wrap-around 语义）、模块 05（9 宫格为什么是 3×3、mask 为什么可缓存）。

### M5 Patch Merging（1h）
- 实现：`PatchMerging`（四路奇偶切片 → cat 4C → LN → Linear(4C→2C)）。
- 验收：`python 06_patch_merging/test_patch_merging.py` 全过；能解释"为什么通道翻倍恰好抵消 token 数 4 倍缩减"（投影计算量每 stage 持平）。

### M6 总装 Swin-T（2h）
- 实现：`SwinTransformer`（4 个 stage、偶数块 W / 奇数块 SW、dpr 线性增长、末尾 LN+池化+头）。
- 验收（三关）：
  ```bash
  python paper/minimal_swin.py
  # 参数量 28,288,354（论文 28.3M ✓）
  # MACs 4.49G（论文 4.5G ✓）
  # (2,3,224,224) -> (2,1000) ✓
  ```
- 深挖：模块 09（参数量逐部件明细表 28.3M 怎么凑出来）。

### M7 过拟合验收（0.5h）
- 8 张随机图 + 20 步 AdamW：loss 应从 ≈ln1000≈6.9 掉到 <0.1（`minimal_swin.py` 验收 3 实测 6.842→0.003）。
- 意义：一次跑通前向+反向+优化器；之后任何改动若破坏梯度通路，这一关立刻暴露。

### M8 小数据训练 + 4 消融（半天）
- CIFAR-100 训练：`python paper/minimal_swin.py --train`（本地数据，不下载）。
- 4 个核心消融（机制层面验证论文主张）：
  ```bash
  python experiments/exp1_global_vs_window.py        # 全局 vs 窗口：MACs 13.8×，纯窗口精度缺口 → 引出 exp2
  python experiments/exp2_window_vs_shifted.py       # 窗口 vs 移位：可达 16 vs 64（最重要）
  python experiments/exp3_patch_merging_ablation.py  # 有无合并：层级表示的价值
  python experiments/exp4_window_size.py             # window 4/7/14：注意力∝M² 与整除性 pad
  ```

## 3. 常见坑 checklist（复现失败时按顺序查）

- [ ] roll 方向反了（mask 与窗口错位，注意是 `-s` 左移、`+s` 回来）
- [ ] permute 后忘了 `.contiguous()`（view 报错/数值错乱）
- [ ] mask 广播顺序写错（应该是 `attn.view(B, nW, h, N, N) + mask[None,:,None]`）
- [ ] 相对索引的混合进制 `dh*(2M-1)+dw` 写成了别的东西（对角线应落在 (0,0)）
- [ ] 用了 post-norm（Swin 是 pre-norm）
- [ ] 换 window_size / 小图训练时没 pad（最后 stage 不整除直接崩）
- [ ] 拿严格 FLOPs（×2）去对论文的 4.5G（论文是 fvcore 口径 = MAC 数）
- [ ] 训练时 shift 块忘了 mask 或 mask 没缓存（每步重复构造会拖慢训练）
