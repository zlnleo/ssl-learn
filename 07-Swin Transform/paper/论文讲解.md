# 论文讲解：Swin Transformer（ICCV 2021 Best Paper）

> **Swin Transformer: Hierarchical Vision Transformer using Shifted Windows**
> Ze Liu, Yutong Lin, Yue Cao, Han Hu, Yixuan Wei, Zheng Zhang, Stephen Lin, Baining Guo（微软亚洲研究院）
> ICCV 2021 口头报告 + **最佳论文奖（Marr Prize）**；arXiv:2103.14030

配套文件：`复现学习路径.md`（怎么动手复现）、`minimal_swin.py`（最小复现代码，三关验收全部 PASS）。

## 1. 一句话总结

> 给 ViT 装上一个 **"带窗口的层级结构"**：注意力只在 **7×7 窗口内**计算（复杂度从 O((hw)²) 降到 O(hw)），相邻两层之间把窗口**循环平移半个窗口**（Shifted Window）让信息跨窗口流动，再像 CNN 一样**逐级降采样、翻倍通道**（Patch Merging）形成多尺度特征——在分类/检测/分割全部任务上超过同量级的 ViT 和 CNN。

## 2. 三大贡献（论文的卖点）

| # | 贡献 | 解决的问题 |
|---|------|-----------|
| 1 | **Shifted Window（SW-MSA）** | 窗口内注意力虽然便宜，但窗口之间零交流；移位让窗口错位跨界，以**几乎零额外计算**实现跨窗口信息流动 |
| 2 | **层级结构（hierarchical）** | ViT 全程单一分辨率；Swin 像 CNN 一样 56→28→14→7 逐级降采样、通道翻倍，天然适配检测/分割等多尺度下游任务 |
| 3 | **线性复杂度** | 全局 MSA 复杂度 O((hw)²)，窗口 MSA 降为 O(hw)（M 固定时），大图上可训练、可推理 |

## 3. 背景：为什么 ViT 需要被改造

论文的出发点（Introduction）是两个"量级"问题：

**痛点 1：计算复杂度平方级。** ViT（Dosovitskiy et al., 2021）把图切成 16×16 的 patch，所有 patch 两两算注意力。设 token 数 $hw$，注意力矩阵是 $hw\times hw$：

$$\Omega(\text{MSA}) = 4hwC^2 + 2(hw)^2C$$

第二项随分辨率**平方**增长：224² 的图切 16×16 patch 有 196 个 token 还能忍，但检测/分割需要高分辨率输入或大特征图，$hw$ 到几千上万时直接爆炸。**图像是稠密信号，token 数天生比 NLP 大一个量级**——这是视觉 Transformer 绕不开的问题。

**痛点 2：单一分辨率。** ViT 全程 16×16 网格，没有 CNN 那种"低层细粒度/高层语义"的金字塔。而检测（FPN）、分割（U-Net）都依赖多尺度特征图。DeiT 等改进提升了 ViT 的分类能力，但没解决这两个结构性问题。

论文 Figure 1 一句话概括动机：**在相同的参数量/算力下，Swin 比 DeiT 精度更高、速度更快**（例如 Swin-T 81.3% vs DeiT-S 79.9%，参数量还略少）。

## 4. 方法逐节精读

### 4.1 总体架构（论文 3.1 节 + Figure 3）

```
输入 224×224×3
  │ Patch Partition（4×4 不重叠切块，通道 3→48→96）          ← 模块 09 PatchEmbed
  ▼
Stage 1: 56×56, C=96   2 个 block（W-MSA + SW-MSA）+ Patch Merging
  ▼                                                          ← 模块 08 BasicLayer
Stage 2: 28×28, C=192  2 个 block + Patch Merging
  ▼
Stage 3: 14×14, C=384  6 个 block + Patch Merging
  ▼
Stage 4: 7×7,  C=768   2 个 block（最后不合并）
  ▼
LayerNorm → 全局平均池化 → Linear 分类头
```

一个 block（论文公式 3）是标准的 pre-norm 双残差：

```
x ──┬─ LN ── W/SW-MSA ──(+)── LN ── MLP(GELU) ──(+)── 输出
    └───────────────────┘     └────────────────────┘
```

与 ViT block 的唯一区别：**注意力换成了窗口版（W-MSA/SW-MSA 交替）**，其余完全一样。这是论文"最小侵入"设计哲学的体现。

### 4.2 W-MSA：复杂度怎么降下来（论文 3.1 节 + Table 1）

把 $hw$ 个 token 按 $M\times M$（默认 $M=7$）切成 $\lceil hw/M^2\rceil$ 个不重叠窗口，**每个窗口内部做完整 MSA**。复杂度对比（论文 Table 1）：

| 算子 | 复杂度 | 56² 图 / C=96 / M=7 数值 |
|---|---|---|
| MSA（全局） | $4hwC^2 + 2(hw)^2C$ | ≈ 2.00G MACs |
| **W-MSA** | $4hwC^2 + 2M^2hwC$ | ≈ 145M MACs（**13.8×**） |
| 注意力部分比值 | $(hw)^2C / M^2hwC = hw/M^2$ | **64×** |

要点：投影部分（第一项）两种方案**完全一样**，省的是注意力点积（第二项）——每个 token 只跟同窗口的 $M^2$ 个邻居算点积。推导详见模块 01 的 `math.md`，实测见 `01_window_attention/experiment.py`。

### 4.3 SW-MSA：论文最巧妙的部分（论文 3.1 节 + Figure 3）

窗口固定的代价：**token 永远看不到窗口外的东西**，堆多层也没用（感受野困死在窗口里）。论文的解法：

> 第 $l$ 层用常规窗口（W-MSA），第 $l+1$ 层把窗口**整体向左上平移 $\lfloor M/2\rfloor$**（SW-MSA），窗口网格错位，原窗口边界处的 token 进入新窗口 → 信息跨窗口流动。两层一组，交替进行。

```
常规窗口（W-MSA）          移位窗口（SW-MSA）
┌───┬───┬───┬───┐        ┌───┬───┬───┬───┐
│   │   │   │   │        │▓▓▓│▓▓▓│▓▓▓│   │
├───┼───┼───┼───┤        │▓▓▓│▓▓▓│▓▓▓│   │
│   │   │   │   │        │▓▓▓│▓▓▓│▓▓▓│   │
├───┼───┼───┼───┤        ├───┼───┼───┼───┤
│   │   │   │   │        │   │   │   │   │
└───┴───┴───┴───┘        └───┴───┴───┴───┘
窗口边界固定              新窗口跨越旧边界（▓ = 来自左上邻窗的 token）
```

**实现技巧（工程等价形式）**：不真的移动窗口网格，而是把特征图**循环移位**（`torch.roll`）后再按老网格切窗——数学上等价，代码零改动。但循环移位会把"空间上不相邻"的区域卷进同一个窗口（图里的 ▓ 与右下角区域），直接算注意力会出错，所以需要 **attention mask**：

- 移位后的图按 3×3 **九宫格**切成 9 块编号 0..8；
- 同一窗口内来自不同编号块的 token 对 = 伪邻居 → 注意力分数加 $-100$，softmax 后 $e^{-100}\approx 0$，权重严格归零；
- 掩码只依赖窗口几何、与输入内容无关 → **可缓存复用**。

细节见模块 04/05 的文档与实验（本项目的"实验 2"：两层后可达 token 数 W-W=16 vs W-SW=64，就是这篇论文方法动机的可视化证明）。

### 4.4 相对位置偏置（论文 3.1 节 + 消融 Table 4）

注意力本身对 token 顺序无感（排列等变），必须有位置信息。论文对比了三种方案（ImageNet Swin-T）：

| 方案 | top-1 |
|---|---|
| 无位置编码 | 80.2 |
| ViT 式绝对位置编码 | 80.6 |
| **相对位置偏置** | **81.3** |

Swin 的做法：注意力分数直接加上一个**只依赖相对位移**的可学习偏置

$$\text{Attention}(Q,K,V) = \text{softmax}\left(QK^\top/\sqrt{d} + B\right)V,\qquad B_{i,j} = \hat B_{(i_1-j_1,\;i_2-j_2)}$$

窗口内相对位移只有 $(2M-1)^2=169$ 种取值（$M=7$），所以 $\hat B$ 只是一张 $(2M-1)^2\times h$ 的小表——**参数几乎免费，还附带平移等变性**。推导与查表索引见模块 03。

### 4.5 Patch Merging：层级结构的来源（论文 3.1 节）

每个 stage 结束把相邻 2×2 patch 合并：

$$H\times W\times C \;\longrightarrow\; \frac{H}{2}\times\frac{W}{2}\times 2C$$

做法：2×2 的 4 个位置按（奇偶行, 奇偶列）分成 4 路 → 通道拼接成 $4C$ → LayerNorm → Linear 压缩到 $2C$。这就是"CNN pooling + 通道翻倍"的 Transformer 版。层级结构让 Swin 的 backbone 能直接接 FPN/U-Net 等检测分割头——这是它拿到 COCO/ADE20K SOTA 的前提。详见模块 06。

### 4.6 变体配置（论文 Table 1）

| 变体 | embed_dim | depths | num_heads | 参数 | FLOPs(MACs) |
|---|---|---|---|---|---|
| **Swin-T** | 96 | (2,2,6,2) | (3,6,12,24) | **28M** | **4.5G** |
| Swin-S | 96 | (2,2,18,2) | (3,6,12,24) | 50M | 8.7G |
| Swin-B | 128 | (2,2,18,2) | (4,8,16,32) | 88M | 15.4G |
| Swin-L | 192 | (2,2,18,2) | (6,12,24,48) | 197M | 34.5G |

> ⚠️ 口径提醒：论文的 "FLOPs" 是 fvcore 口径，**把 1 次乘加（MAC）计为 1 FLOP**。
> 严格口径 1 MAC = 2 FLOPs，Swin-T 应算约 9G。本项目的计数器同时给出两个口径。

## 5. 实验部分解读（论文 4 节）

**ImageNet-1K 分类（Table 2/3）**：Swin-T 81.3% / Swin-S 83.0% / Swin-B 83.5%（224²；B@384 达 84.5%），以更少参数/更快推理超过 DeiT 系列。Figure 1 的"精度-速度"曲线是这篇论文被记住的第一张图：**同等速度下精度最高，同等精度下速度最快**。

**COCO 检测（Table 5）**：Mask R-CNN / Cascade Mask R-CNN 换 Swin backbone 后全面超过 ResNet-50 基线（如 Cascade Mask R-CNN + Swin-T box AP 50.4 vs ResNet-50 46.3 左右）。**注意**：这也是论文的"隐藏卖点"——mask 指标提升靠的是**层级多尺度特征**，说明 Swin 的价值不止在分类。

**ADE20K 分割（Table 6）**：UperNet + Swin-T mIoU 44.5，超过同量级 CNN/ViT。

**消融（Table 4）**：① shift 从 0 加大到 window/2 精度单调上升 → 跨窗口连接是真需求；② 位置编码三者对比（见 4.4）；③ 各变体用相对偏置都稳赢。

## 6. 为什么能拿 Best Paper

1. **问题选得准**：抓住 ViT 两个结构痛点（复杂度、单尺度），解法直击要害；
2. **机制优雅**：shifted window 用"循环移位 + 掩码"这种近乎零成本的方式解决跨窗口通信，没有引入任何新算子；
3. **工程完整**：28M~197M 四个变体 + 分类/检测/分割三任务 SOTA，可复现、可直接用；
4. **后继影响大**：Swin 成为此后几年视觉 backbone 的默认基线（SwinV2、以及大量下游工作的底座）。

## 7. 局限与后续

- **窗口尺寸固定**：7×7 是经验值；本项目"实验 4"实测了 window 4/7/14 在 FLOPs 与整除性 pad 上的真实代价（8.98G / 9.37G / 11.38G）。
- **训练不稳定 / 分辨率泛化**：SwinV2（CVPR 2022）指出大模型/高分辨率下训练不稳定，提出 residual-post-norm + 对数间隔的连续位置偏置 + scaled cosine attention 三个改进——建议作为进阶阅读。
- 循环移位+mask 的 9 宫格构造是复现时最容易写错的地方（见复现要点）。

## 9. 复现要点：论文没写、但代码必须做对的细节

1. **roll 方向**：`torch.roll(x, shifts=(-s, -s), dims=(1, 2))` 向左上移；返回时 `+(s, s)` 移回。写反了 mask 会整体错位，且单元测试必须覆盖"roll 前后语义"。
2. **mask 的 9 宫格**：切片是 `(0:-M), (-M:-s), (-s:None)` 三行三列，编号顺序必须与窗口划分顺序一致；mask 在 `softmax` **之前**加 $-100$。
3. **mask 广播**：mask 形状是 `(nW, M², M²)`，一个样本的窗口数；batch 内所有样本共享。加 mask 时要 `attn.view(B, nW, h, N, N) + mask[None, :, None]` 再 view 回来——顺序写错就全废。
4. **contiguous**：`permute` 后必须 `.contiguous()` 才能 `view`，否则报错或数值错乱（模块 02 专门讲了 strides）。
5. **LN 位置**：pre-norm（LN 在注意力/MLP 之前），不是 ViT 原版的 post-norm。
6. **相对偏置索引**：`(dh, dw)` 平移 $M-1$ 后按 `dh*(2M-1)+dw` 展平——是"混合进制"，不是 `dh*(2M-1)+dw` 之外的任何写法；对角线必须落在位移 (0,0) 的行上。
7. **整除性与 pad**：224/7 配置全程整除；换 window_size（如 14）或小图训练时，最后 stage 不整除，必须 pad 到窗口整数倍再 crop（工程版 `swin/block.py` 已内置，论文没有提这点）。
8. **训练配方（想刷 81.3% 才需要）**：AdamW lr=1e-3（batch 1024 线性缩放）、cosine + 20 epoch warmup、weight decay 0.05、drop path 0.2（T）、EMA、RandAug/RepeatedAug/Mixup/Cutmix。**这些不影响模型机制**，最小复现不需要。
