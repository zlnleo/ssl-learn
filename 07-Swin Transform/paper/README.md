# 论文层三件套：讲解 / 路径 / 最小复现代码

| 文件 | 内容 | 怎么用 |
|---|---|---|
| `论文讲解.md` | 逐节解读 ICCV 2021 Best Paper（动机→方法→实验→局限 + 复现要点） | 读论文前后对照看，第 9 节是复现避坑清单 |
| `复现学习路径.md` | M0-M8 八个里程碑，每个都有**可执行验收标准**（具体数字） | 按里程碑顺序动手，过了验收才算懂 |
| `minimal_swin.py` | 单文件最小复现（约 350 行，torch only，每段标注模块编号） | 运行即验收：参数/FLOPs 对表 + shape + 过拟合 |

## 运行

```bash
conda activate ssl_cv
python paper/minimal_swin.py          # 三关验收（参数 28.3M / MACs 4.5G / 过拟合）
python paper/minimal_swin.py --train  # 追加 CIFAR-100 小规模训练（本地数据，不下载）
```

## 验收实测（本机 ssl_cv / RTX 4060）

- 参数量 **28,288,354**（论文 28.3M ✓）
- MACs **4.49G**（论文 4.5G，fvcore 口径 ✓；严格口径 ≈9 GFLOPs）
- 前向 (2,3,224,224) → (2,1000) ✓
- 过拟合：8 图 × 20 步，loss 6.842 → 0.003 ✓（梯度通路正确）

## 与项目其它部分的关系

- `minimal_swin.py` = 最小版（读代码用，一行对一公式）；
  `swin/` 包 = 工程版（消融开关/任意尺寸/被 train.py 与 experiments 复用）；
  `01-09` 模块 = 每个机制的深挖教材（文档 + 推导 + shape 实验 + 测试）。
- 复现顺序建议：`复现学习路径.md` 的 M0-M8 → 对照 `01-09` 深挖 → 工程训练用 `train.py`。
