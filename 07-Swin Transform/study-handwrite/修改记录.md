## 逐文件详细说明

### 1. `model/model.py`（致命错误，已重写）

| 原问题 | 后果 | 修复 |
|---|---|---|
| `self.num_layers` 未定义就被用（`num_features`、`downsample` 判断） | 构造即 `AttributeError` | 构造里补 `self.num_layers = len(depths)` |
| `BasicLayer(...)` 传 `num_head=`（应为 `num_heads=`） | `TypeError: unexpected keyword 'num_head'` | 改正关键字 |
| `BasicLayer(...)` 传 `drop_path_rate=`（应为 `drop_path=`），且没按 stage 切 dpr | `TypeError` | 传 `drop_path=dpr[本stage区间]` |
| `downsample=patch_merging`（bool） | `TypeError: 'bool' object is not callable` | 改为传真正的 `PatchMerging(dim)` 或 `None` |
| `patch_embed` 写死 `Conv2d(3,...)` | FashionMNIST(1通道) 崩溃 | 用参数 `in_channels` |
| `forward_features` 在 patch 前用 `//window_size` 算 H,W；conv 输出没展平成 token 序列；`norm` 放进 stage 循环每层都调 | 形状/维度全错 | patch 后 `flatten(2).transpose(1,2)` → token 序列；H,W 用 patch 后网格；所有 stage 结束后统一 `self.norm` 一次 |

### 2. `model/window.py`（一行笔误，但必崩）

```python
# 原（错）：(-shift_size, None) 是裸元组，被当成高级索引 → dtype 报错
h_slices = (slice(0,-window_size), slice(-window_size,-shift_size), (-shift_size, None))
# 修复：补上 slice()
h_slices = (slice(0,-window_size), slice(-window_size,-shift_size), slice(-shift_size, None))
```

### 3. `utils/utils.py`（DropPath 静默失效）

```python
noise = keep_prob + torch.rand(shape, dtype=x.dtype, device=x.device)
noise.floor()        # 原：floor() 返回新张量，结果被丢弃 → drop 从未生效
noise = noise.floor()  # 修复：重新赋值
```

### 4. `utils/save.py`（原来是空文件）

新增两个函数：
- `save_checkpoint(path, model, epoch, best_acc, config, optimizer, scheduler, scaler)`：best.pt 只传 model 部分；last.pt 把优化器/调度器/scaler 一起存 → 支持 `--resume`。
- `load_checkpoint(path, model, optimizer, scheduler, scaler, map_location)`：按 key 恢复，返回 ckpt dict。

### 5. `__init__.py` + 导入方式（model / utils / train）

问题：model、utils 没有 `__init__.py`，`attention.py` 靠 `sys.path.append(硬编码路径)`，其它模块用裸导入（`from attention import ...`），单跑必 ImportError。
修复：
- `model/__init__.py`、`utils/__init__.py` 新增（文件夹升级成正式"包"）；
- 所有跨文件引用统一成**以 study-handwrite 为根的绝对导入**：
  - `model/model.py`：`from model.patch import PatchMerging` / `from model.layer import BasicLayer`
  - `model/block.py`：`from model.attention import WindowAttention` / `from model.window import ...` / `from utils.utils import DropPath`
  - `model/layer.py`：`from model.block import SwinBlock`
  - `model/attention.py`：`from utils.position import build_relative_position_index`（删掉硬编码 sys.path）
- `train.py` 顶部自动把自己所在目录插进 `sys.path`，保证从任何目录 `python train.py` 都能 import。

> 为什么不用相对导入 `from .attention import`？见同目录学习文件《学习笔记_文件夹之间如何传递.md》第 3 节。

### 6. `train.py`（main 原来是空的，已按 reviewlearn 补全）

复刻 `vit/reviewlearn.py` 骨架，内容包含：
`set_seed`（含 cudnn 确定性/worker 种子）、CIFAR-100 与 FashionMNIST 两个数据集工厂、
`build_model`（迷你 Swin：patch=4、window=4、depths=(2,2,2)、heads 由 embed_size/32 推导）、
`train_one_epoch`（AMP + 梯度裁剪）、`evaluate`、CosineAnnealingLR、best/last checkpoint、
`--resume` 断点续跑、early-stop patience、TensorBoard + `run_时间戳` 日志目录。
