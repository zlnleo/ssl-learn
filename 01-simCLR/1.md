# SimCLR 学习总结

> SimCLR: A Simple Framework for Contrastive Learning of Visual Representations

---

# 1. SimCLR整体目标

## 核心思想

SimCLR不是学习分类。

它的目标：

> 学习一个能够提取图像语义信息的 Encoder。

最终得到：

```
image
 |
Encoder
 |
feature representation
 |
downstream task
```

这个feature可以用于：

- 分类
- 检测
- 分割
- 检索


---

# 2. SimCLR整体流程

```
                image

                  |

          Encoder       Encoder

             |             |

            hi            hj

             |             |

      Projection Head  Projection Head

             |             |

            zi            zj


                  |

          Contrastive Loss


```

# 3. Data Augmentation


## 作用

⭐ augmentation不是简单的数据扩充。

它告诉模型：

> 这些变化不影响图片的语义，它们应该被认为是同一个东西。


例如：

同一只猫：

```
原图

↓

裁剪

↓

颜色变化

↓

翻转

```


模型应该认为：

```
feature(xi)
≈
feature(xj)
```


---

## SimCLR常用增强


```python
RandomResizedCrop

RandomHorizontalFlip

ColorJitter

RandomGrayscale

Normalize
```


---

# ⚠️ 易错点1

## augmentation不是生成标签


错误理解：

```
增强图片
=
新的训练类别
```


正确：

```
增强图片
=
同一个图片的新视角
```


---

# 4. Encoder


## 作用

Encoder负责：

```
image
 |
CNN
 |
feature h
```


例如：

ResNet18:

```
输入:

3×32×32


输出:

512维feature

```


代码：

```python
self.model.fc = nn.Identity()
```


---

# 为什么删除fc？


ResNet原本：

```
image

↓

ResNet

↓

512 feature

↓

fc

↓

1000分类
```


ImageNet分类。


SimCLR需要：

```
image

↓

ResNet

↓

512 feature

```


所以：

删除分类层。


---

# ⚠️ 易错点2

## Encoder不是分类器


SimCLR训练过程中：

没有：

```
cat
dog
car
```

标签。


Encoder学习的是：

```
图片之间的关系
```


---

# 5. Projection Head


代码：

```python
h = encoder(x)

z = projection(h)
```


结构：

```
Encoder

↓

h

↓

Projection Head

↓

z

```


---

# 为什么需要Projection Head？


这是SimCLR最容易混淆的地方。


## 错误理解：

```
projection head
=
分类层
```


错误。


---

## 正确理解：

Projection Head是：

> 专门为了对比学习设计的空间转换层。


Encoder学习：

```
通用视觉特征
```


Projection Head负责：

```
让feature适合contrastive loss
```


---

论文发现：

如果直接：

```
encoder feature
↓

contrastive loss

```

效果不好。


加入：

```
encoder

↓

projection

↓

loss

```

效果更好。


---

# ⚠️ 易错点3

训练结束后：

不要使用projection head。


保存：

```
encoder
```

而不是：

```
encoder + projection
```


原因：

projection只是训练辅助。


---

# 6. Positive和Negative


SimCLR没有人工标签。


Positive：

```
同一张图片不同增强
```


例如：

```
xi

xj

```

属于positive pair。


---

Negative：

batch里面其他图片。


例如：

batch:

```
cat

dog

car

tree
```


cat增强:

```
cat1

cat2
```


positive:

```
cat1-cat2
```


negative:

```
cat1-dog

cat1-car

cat1-tree

```


---

# 7. NT-Xent Loss


核心目标：

增加：

positive similarity


降低：

negative similarity


公式思想：


```
positive越接近

negative越远

loss越小

```


---

代码：

```python
similarity=torch.matmul(z,z.T)
```


计算：

```
每一个样本和所有样本的相似度
```


---

# 为什么normalize?


代码：

```python
F.normalize(z,dim=1)
```


作用：

计算cosine similarity。


否则：

模型可能通过增大向量长度作弊。


---

# 8. 为什么mask自己？


代码：

```python
similarity.masked_fill_(mask,value)
```


因为：

自己和自己：

```
similarity=1
```


一定最大。


模型会偷懒。


所以删除。


---

# ⚠️ 易错点4

AMP情况下不要写：

```python
-1e9
```


因为：

FP16无法表示。


推荐：

```python
torch.finfo(
similarity.dtype
).min
```


---

# 9. AMP混合精度


## 作用

提高GPU训练速度。


使用：

```
FP16 + FP32
```


---

训练：

普通：

```
FP32
```


AMP：

```
部分FP16

重要部分FP32

```


---

# GradScaler


代码：

```python
scaler.scale(loss).backward()

scaler.step(optimizer)

scaler.update()
```


---

原因：

FP16容易：

```
gradient underflow
```


例如：

```
0.00000001

↓

FP16

↓

0
```


所以：

先放大loss：

```
loss × scale
```


backward之后：

再恢复。

# 10. 保存模型



例如：

```python
torch.save(
model.encoder.state_dict(),
"encoder.pth"
)
```


---

不要保存：

```
projection head
```


因为：

下游任务不需要。

# 11. SimCLR验证方法


SimCLR没有训练accuracy。


使用：

## Linear Evaluation


流程：

```

        |

image

        |

encoder

        |

feature

        |

Linear classifier

        |

class
```


---

只训练：

```
Linear layer
```


不训练：

```
encoder
```


---

# 为什么？


测试：

encoder feature是否有语义。


如果：

feature很好：

简单Linear也能分类。


---

# ⚠️ 易错点5

Linear Evaluation不是重新训练模型。


错误：

```
encoder + classifier一起训练
```


正确：

```
encoder冻结

classifier训练
```

SimCLR:

答案：

让模型知道哪些变化不影响语义。

答案：

告诉模型哪些应该接近。

答案：

让encoder输出映射到适合contrastive loss的空间。

答案：

projection只是训练辅助。

答案：

测试encoder表示能力。
