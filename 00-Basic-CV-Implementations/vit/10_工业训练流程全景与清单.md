## 三、顺手先补：验证与早停（10 分钟）

**早停（early stopping）**：验证指标连续 N 个 epoch 不涨就自动停止，防止过拟合也省算力。

```python
# 训练循环里，替代"永远跑满 epochs"：
patience, bad_epochs = 10, 0          # 连续 10 轮不涨就停
if test_acc > best_acc:
    best_acc = test_acc
    bad_epochs = 0                    # 创新高 -> 重置计数
else:
    bad_epochs += 1
if bad_epochs >= patience:
    log(f"早停：验证集 {patience} 轮未提升，停止于 epoch {epoch}")
    break
```

**更完整的验证流程**（阶段二科研用）：验证集选超参 → 测试集只测一次、不回头调参——测试集被反复看就"漏题"了，这是科研红线。
