# 16 · 训练脚本版本对照与使用指南

> 六个版本的 train 脚本总地图：每个版本 = 初始版 + 一个独立功能，**互不混合**。
> 用法：想学哪个功能就打开哪个版本（每个文件头部自带使用指南），
> 并在 PyCharm 里和 `train.py` 做 diff——一眼看出这个功能改了什么。
> 全部版本已在本机实测通过（除 hydra 需装在 ssl_cv 环境外无额外依赖）。

## 二、每个版本的用法速查

### v2 TensorBoard

```bash
python train_v2_tensorboard.py --dataset toy --epochs 5
tensorboard --logdir runs          # 另开终端，浏览器打开 localhost:6006
```

改动就 4 处（文件里都有 `【本版新增】` 标记）：import SummaryWriter → 建 writer（事件文件写进 `runs/run_xxx/tfboard/`）→ 每 epoch 记 5 条曲线 → 结束写 hparams + close。
**验证点**：跑完后 `runs/run_xxx/tfboard/` 下有 `events.out.tfevents...` 文件；看板里能看到 train/test/lr 曲线。

### v3 早停

```bash
python train_v3_earlystop.py --dataset toy --epochs 50 --patience 5
```

改动 3 处：`--patience` 参数 → `bad_epochs` 计数器 → 循环里"创新高清零，否则 +1，到阈值 break"。
**实测**：`--patience 1` 时第 2 个 epoch 就打印 `[early stop]` 提前收工。
**易错点**（文件里有注释）：判断必须和"是否创新高"写成 if/else 配对，独立写 `if test_acc <= best_acc` 会在创新高那轮误判。

### v4 可复现性

```bash
python train_v4_reproducible.py --dataset toy --epochs 3
# 同样命令跑两次，指标应完全一致
```

改动 3 处：`set_seed()` 完整版（补 random/numpy 种子 + cudnn 确定性开关）→ 三个 loader 加 `worker_init_fn` → main 改用 set_seed。
**核心认知**：num_workers>0 时子进程随机数不受主进程种子控制，不固定 worker 种子，"复现不了"就是它。

### v5 hydra（装到 ssl_cv）

```bash
pip install hydra-core omegaconf        # 装进你的 ssl_cv 环境（已装好）
python train_v5_hydra.py                # 用 configs/train_cifar100.yaml
python train_v5_hydra.py dataset=toy epochs=5          # 命令行覆盖配置
python train_v5_hydra.py -m lr=1e-3,3e-3 dataset=toy   # 网格搜索
```

改动核心 3 处：入口换成 `@hydra.main` → 参数从 cfg 取 → 路径用 `get_original_cwd()` 解析（hydra 会切换工作目录，不处理的话产物会散落到 outputs/ 里）。
**实测**：`dataset=toy` 覆盖生效，训练正常，配置快照自动存 outputs/。

### v6 DDP

```bash
# 单进程模式（和初始版行为一致）：
python train_v6_ddp.py --dataset toy --epochs 3
# 多卡（Linux 服务器）：
torchrun --nproc_per_node=4 train_v6_ddp.py --batch-size 32
```

改动 6 处（对应 12 文档模板）：进程组初始化 → rank0 才写日志 → DistributedSampler → DDP 包装 → 每 epoch `sampler.set_epoch` → 只 master 评估/保存。
**本机 Windows 特供**：这台机器的 torch 缺 libuv，torchrun 会报 `use_libuv` 错误。改用 file:// 集合点手动起两个进程（命令见 v6 文件头部）。**实测**：2 进程 exit 0，`总 batch = 32 x 2 = 64`，每 rank 分到一半数据，rank1 日志为空。
**关键换算**：总 batch = 每卡 batch × 卡数；lr 随总 batch 线性缩放；保存时 DDP 模型要 `.module` 才是原始模型。

## 三、怎么用这套版本（学习法）

1. **一次只开一个版本**：先读文件头部"使用指南"，再扫全文里 `【本版新增】` 标记，其余部分和初始版一模一样不用重读；
2. **用 PyCharm 的 diff**：右键文件 → Compare With → 选 `train.py`，改动一目了然——这是最有效的学习姿势；
3. **改参数做实验**：每个版本都支持 toy 数据集离线快跑，改一个参数看一个现象；
4. **合流**：当你觉得某个功能已经内化了，可以把它合并进你自己的 `train.py`（合并 = 把 `【本版新增】` 的代码搬过去）。

## 四、常见问题

- **tensorboard 打开是空的**：`--logdir` 要指到 runs（事件文件的父目录）；
- **hydra 报 import 错误**：装错环境了——要装在 ssl_cv（`D:\env\anaconda\envs\ssl_cv` 的 python），不是 base；
- **v6 torchrun 报 use_libuv**：本机 torch 的已知问题，用文件头部的 file:// 手动启动方式；Linux 上没这个问题；
- **版本之间会互相影响吗**：不会——checkpoint/ 和 runs/ 是共享产物目录但每次运行各自写各自的（run_时间戳 隔离），模型接口完全一致，可以混着跑。
